# 风水地球仪 · 用户手册

本手册面向**终端用户**，介绍风水地球仪的功能与使用方法。
开发者与部署人员请参阅 [README.md](../README.md)。

---

## 一、产品简介

风水地球仪是一款基于 3D 卫星地球仪的风水罗盘应用。你可以在真实卫星地图上浏览全球、任意选点，即时查看该地的位置、海拔、实时天气与八卦方位，并基于地理数据进行 AI 风水分析。

主要能力：

- 🌍 3D 卫星地球仪（天地图高清卫星影像 + 中文地名注记）
- 📍 点击 / GPS 一键选点，自动获取经纬度、海拔、地址
- 🌤️ 所选位置的实时天气（温度 / 湿度 / 风向 / 风速 / 天气状况）
- 🧭 八卦方位推算
- 🔮 基于地理信息的 AI 风水分析（开发中）

## 二、访问与登录

### 2.1 打开应用

浏览器访问前端主应用地址（默认本地开发：<http://localhost:8110/front>）。

### 2.2 注册账号

进入注册页，支持两种方式：

| 方式 | 需要的信息 |
|------|-----------|
| 手机号注册 | 手机号 + 短信验证码 + 密码（≥6 位，需确认） |
| 邮箱注册 | 邮箱 + 邮箱验证码 + 密码 |

> 手机号需符合 `1[3-9]xxxxxxxxx` 格式；验证码有效期内有效。

### 2.3 登录

登录页提供四种方式，可自由切换：

1. **账号 + 密码**：输入手机号或邮箱（系统自动识别类型）+ 密码。
2. **手机号 + 短信验证码**。
3. **邮箱 + 邮箱验证码**。
4. **微信扫码**：弹出二维码，用微信扫码后在手机端确认登录。

> 验证码按钮有 60 秒倒计时冷却。

## 三、主界面 · 3D 地球仪

登录后进入主界面，左侧（移动端为顶部）为导航栏，中央为 3D 卫星地球仪。

### 3.1 地球仪操作

| 操作 | 说明 |
|------|------|
| 拖拽 | 旋转地球，改变视角 |
| 滚轮 / 双指 | 缩放 |
| **左键点击地表** | 选取该点为当前位置（出现红色标记） |
| 📍 定位按钮（右下角） | 使用本机 GPS 定位到当前位置 |

底图为天地图**卫星影像**，叠加**中文地名注记**；未配置地图密钥时回退为默认底图。

### 3.2 信息侧栏

选点后，右侧（移动端为底部抽屉）信息栏显示：

**位置信息**
- 经度 / 纬度（6 位小数）
- 海拔（米，由高程数据源实时查询）
- 八卦方位（基于经度推算：坎 / 艮 / 震 / 巽 / 离 / 坤 / 兑 / 乾）
- 地址（逆地理编码，如「北京市东城区…」）

**天气信息**
- 天气状况（晴 / 阴 / 雨 / 雾…）
- 温度（°C）
- 湿度（%）
- 风向（西南风、北风…）
- 风速（km/h）

> 选中新位置时数据会自动刷新；刷新期间显示「加载中…」。侧栏可通过 ◀ / ▶ 按钮收起展开。

## 四、风水分析

在信息栏点击 **「开始风水分析」**，进入分析页：

1. 页面会自动获取并展示所选位置的完整上下文：经纬度、海拔、地址、八卦方位、实时天气。
2. 点击 **「开始风水分析」** 按钮，AI 会基于上述信息生成风水分析报告（含总体评价、地形与海拔、气候与天气、八卦方位、布局择址建议、综合评分 0–100），并自动存档。
3. 生成约需数秒到十余秒，期间按钮显示「分析中…」；完成后可点击「重新分析」再次生成。
4. 若 AI 服务未配置或异常，会给出提示，可稍后重试。

> 分析结果由 AI 生成，仅供文化参考与娱乐，不构成专业堪舆或决策建议。每次分析会保存为历史记录（历史页展示待后续接入）。

## 五、历史记录

「历史记录」页（导航栏或个人中心进入）展示所有已生成的风水分析：

- 每条记录显示**地点、综合评分、生成时间**与天气概况。
- 点击一条记录可**展开**查看完整分析内容；再次点击收起。
- 每条可**删除**（需确认）。
- 数据较多时点击「**加载更多**」翻页。

> 记录由「风水分析」生成时自动保存。仅展示当前账号的分析。

## 七、数据来源

应用展示的地理数据均来自权威服务，仅供参考：

| 数据 | 来源 |
|------|------|
| 卫星底图 | 天地图（国家地理信息公共服务平台） |
| 地址 / 时区 | 高德地图逆地理编码 |
| 海拔 | Open-Meteo（主）→ OpenTopoData（备），自动降级 |
| 天气 | 和风天气 QWeather |

> 海拔为地形高程近似值，山顶、深谷等剧烈起伏处可能有偏差；天气为所选坐标的实时观测值。

## 九、常见问题

**Q：点击地球后海拔一直显示「加载中…」？**
A：高程数据源暂时无响应，稍候会自动降级到备用源；若持续无数据，多为该点位于深海或无地形覆盖区域。

**Q：天气显示「暂无天气数据」？**
A：所选坐标超出和风天气覆盖范围，或服务暂时不可用，请尝试换一个位置。

**Q：地图加载不出来？**
A：底图依赖天地图密钥。若未配置或网络受限，会回退为默认底图；请检查网络或联系管理员。

**Q：微信扫码登录无反应？**
A：当前为模拟实现，扫码后请在模拟界面中点击「确认登录」。
